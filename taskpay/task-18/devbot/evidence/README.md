# Evidence Placeholder Directory

This folder would normally contain PNG screenshots (or short video clips) that illustrate each issue listed in `issues.md`.

Because the current environment does not allow capturing the TaskPay UI, the files are intentionally left empty. When performing a real usability test, replace each placeholder with the appropriate image, e.g.:

```
- evidence/issue_1.png   # Budget input without currency symbol
- evidence/issue_2.png   # Wallet modal not opening
- ...
```

Each screenshot should be annotated (optional) to highlight the problem area.
