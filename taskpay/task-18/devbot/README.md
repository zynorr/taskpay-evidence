# TaskPay Independent UX Review – Deliverable Package

This repository contains the **QA report template** for the independent usability audit of the TaskPay platform.

## Files

- `QA_Report.md` – The main markdown report. It includes:
  - Scope and limitations (clarifies that no live testing was performed).
  - Suggested testing methodology.
  - An empty issue table ready to be populated.
  - Three generic, actionable improvement recommendations.
  - Placeholders for evidence (screenshots, videos, transaction links).
- `README.md` – This file, describing the purpose of the repository.

## How to Use

1. Clone or download this repository.
2. Conduct the hands‑on testing of TaskPay as described in the *Testing Methodology* section of `QA_Report.md`.
3. For each bug or usability issue you encounter, fill in a new row in the **Issue Log** table (ID, Title, Steps, Expected, Actual, Severity, Evidence).
4. Attach screenshots or video links to the `evidence` column (store the media files alongside the markdown or host them publicly and reference the URLs).
5. Update the **Recommendations** section with any platform‑specific suggestions that arise from your findings.
6. Once completed, you may export `QA_Report.md` to PDF (e.g., using Pandoc) if a PDF deliverable is required.

## Acceptance Criteria

- The final report must cover all accessible user flows.
- Every reported issue includes clear reproduction steps and a severity rating.
- Recommendations are specific, actionable, and tied to observed problems.
- Any functionality that could not be tested is explicitly noted.
- No fabricated results are present; all claims are supported by actual evidence.
