# TaskPay UX QA Report

This repository contains the deliverables for the independent UX testing task for **TaskPay**.

- `QA_Report.md` – The main QA report in Markdown format.
- `Issues_List.md` – A concise table of identified issues (none were found due to limited access).
- `Screenshots/` – Placeholder directory for any screenshots that would be attached in a real test.

The report follows the required acceptance criteria and clearly notes any functionality that could not be tested.
