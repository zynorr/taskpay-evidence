# TaskPay UX QA Deliverable

This repository contains the deliverables for the **TaskPay user‑experience quality assurance** assignment.

## Files

- `QA_Report.md` – The main quality‑assurance report written in Markdown. It includes:
  - Overview of tested user flows
  - Identified issues with severity, reproduction steps, and placeholder evidence
  - Five concrete, actionable recommendations
  - Limitations of the testing performed

- `README.md` – This file, providing a short description of the repository contents.

## How to Use

1. Open `QA_Report.md` in any Markdown viewer (VS Code, GitHub, typora, etc.) to read the full analysis.
2. Replace the placeholder image references (e.g., `/assets/screenshots/ui-001.png`) with actual screenshots if you later perform hands‑on testing on the live platform.
3. Use the issue table and recommendations as a starting point for a development or design sprint.

## Disclaimer

The reviewer (ChatGPT) does **not** have access to the live TaskPay application, wallets, or any private data. All observations are based on visual inspection of publicly available pages and standard UX principles. No real bugs were reproduced; placeholders are provided where visual evidence would normally appear.
