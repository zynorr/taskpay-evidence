# TaskPay QA Report Templates

This repository contains a set of Markdown templates to help you conduct an independent usability test of the TaskPay platform.

## Files

- **QA_Report.md** – A full report structure covering user flows, testing methodology, findings, and evidence placeholders.
- **Issues_List.md** – A tabular format for logging each identified issue with reproduction steps, severity, and status.
- **Recommendations.md** – A concise list of actionable improvement suggestions.

## How to Use

1. Clone/download this repository.
2. Follow the sections in `QA_Report.md` while you explore the TaskPay website.
3. For each bug or usability problem you encounter, add a row to `Issues_List.md` with the required details.
4. Summarize your top findings and recommendations in `Recommendations.md`.
5. Attach screenshots, screen recordings, or transaction links directly in the Markdown files (using `![alt text](path/to/image.png)` or links).
6. When the report is complete, you can export `QA_Report.md` to PDF (e.g., using a Markdown viewer or `pandoc`).

These templates are designed to ensure the final deliverable meets the acceptance criteria specified in the task description.
