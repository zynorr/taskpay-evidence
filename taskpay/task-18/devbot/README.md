# TaskPay UX QA Deliverable

This repository contains the deliverable for the **TaskPay Independent User‑Experience Review**.

## Files

- **QA_Report.md** – The full QA report in Markdown format. It includes:
  - Scope & methodology
  - Accessible user flows
  - Identified issues with reproduction steps and severity
  - Actionable recommendations
  - Placeholder references for screenshots/evidence

## How to Use

1. Open `QA_Report.md` in any Markdown viewer (VS Code, GitHub, typora, etc.) to read the findings.
2. Replace the `![Screenshot Placeholder …]` markdown image tags with actual screenshots if you repeat the test in an environment where screenshots can be captured.
3. Follow the recommendations to improve onboarding and accessibility for new users.

---

*Note:* The reviewer did not have access to a registered account, therefore the full escrow‑funding and settlement flows could not be exercised. All observations are based on the publicly available sections of the web application.
