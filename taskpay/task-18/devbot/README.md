# TaskPay UX Review Deliverable

This repository contains the deliverables for the independent user‑experience review of the **TaskPay** platform as requested.

## Files

- **report.md** – The main QA report in Markdown format. It outlines the user flows we were able to examine, documents the testing approach, lists any identified issues (none were discovered due to access limitations), and provides concrete, actionable recommendations.
- **issues.csv** – A CSV file summarizing any bugs or usability problems. Since we could not interact with the live system, the file currently contains a placeholder entry indicating that testing could not be performed.

## How to Use

1. Open `report.md` to read the full assessment.
2. Review `issues.csv` for a structured view of any problems (currently none).
3. Use the recommendations in the report to guide improvements to the TaskPay UI/UX.

**Note:** No screenshots or transaction links are included because the reviewer environment does not have network access to the live TaskPay site.
