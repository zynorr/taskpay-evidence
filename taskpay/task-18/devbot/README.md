# TaskPay QA Report

This repository contains the QA deliverable for the **TaskPay** user experience review.

## Files

- `report.md` – The main QA report in Markdown format, including tested flows, findings, issues, and recommendations.
- `issues.md` – A concise list of identified issues with reproduction steps and severity (empty due to testing constraints).

The report follows the acceptance criteria provided in the task description.
