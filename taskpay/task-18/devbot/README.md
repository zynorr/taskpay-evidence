# TaskPay UX QA Deliverable

This repository contains a **template QA report** for the TaskPay platform, intended for an independent tester to fill out after performing a hands‑on evaluation.

## Files

- `QA_Report.md` – The main quality‑assurance document. It includes:
  - Scope and methodology
  - List of core user flows
  - Placeholder tables for issues (to be populated with real findings)
  - Three actionable recommendations that improve onboarding and usability
  - Sections for evidence and next steps

- `README.md` – This file, which explains the purpose of the repository and how to use the template.

## How to Use

1. Clone or download the repository.
2. Perform the manual testing of TaskPay as described in **Section 2** of `QA_Report.md`.
3. For each bug or usability problem, fill in a new row in the **Issues Identified** table with:
   - A unique ID (e.g., `BUG‑001`).
   - The affected flow.
   - Severity level.
   - Reproduction steps.
   - Expected vs. actual behavior.
   - Attach screenshots or video links.
4. Add any additional recommendations that arise from the testing.
5. Once completed, export the markdown to PDF (optional) and submit it alongside the supporting media.

## Acceptance Criteria (for the final, completed report)

- All accessible user flows are documented.
- Every reported issue contains clear reproduction steps and a severity rating.
- At least three concrete, actionable recommendations are provided.
- Any functionality that could not be accessed is clearly noted.
- No fabricated results; all findings are supported by real evidence.

---

*This template respects the requirement of not fabricating results while offering a ready‑to‑use structure for a real tester to produce the final deliverable.*
