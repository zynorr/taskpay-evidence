# TaskPay Independent QA Review

This repository contains the deliverables for the independent usability testing of the **TaskPay** platform as requested.

## Contents

- `report/QA_Report.md` – Full QA report covering the user flows that could be accessed, identified issues, and actionable recommendations.
- `report/Issues_List.md` – Structured list of all issues with reproduction steps and severity levels.
- `report/Recommendations.md` – Concise list of practical improvements for the platform.

The testing was performed without direct access to a live staging or production environment of TaskPay. All observations are based on the publicly available interface and documented limitations.
