# TaskPay UX QA Deliverable

This repository contains the deliverables for the **TaskPay UX QA** assignment.

## Files

| File | Description |
|------|-------------|
| `QA_Report.md` | Full markdown QA report, including user‑flow overview, inferred issues, severity, reproduction steps, and actionable recommendations. |
| `issues.csv` | Tabular list of identified issues (ID, Title, Severity, Steps, Expected behavior) suitable for import into issue‑tracking tools. |
| `README.md` | This file – provides an overview of the repository contents. |

## How to Use

1. Open `QA_Report.md` in any markdown viewer to read the detailed analysis.
2. Import `issues.csv` into your preferred project management system (Jira, GitHub Issues, etc.) to start tracking the bugs.
3. The report notes which parts of the platform could not be tested due to lack of live access. A human tester should follow the listed reproduction steps and capture screenshots/video evidence for each confirmed issue.

---

### Disclaimer

The findings are **hypothetical** and derived from publicly available documentation and typical UX patterns. They have not been validated on a live instance of TaskPay. Please conduct a hands‑on QA session to verify the issues and collect concrete evidence.
