## How to Use

1. Review the `QA_Report.md` for a concise overview of the findings.
2. If you have access to a staging or sandbox version of TaskPay, replicate the steps listed under each issue to verify them.
3. Replace the placeholder screenshots with actual captures and commit them to the `screenshots/` folder.
4. Share the report with the development team for triage and implementation of the recommended improvements.
