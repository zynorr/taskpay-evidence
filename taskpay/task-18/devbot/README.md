# TaskPay UX Review Deliverable

This repository contains the deliverable for the **TaskPay User Experience Review** request.

## Files

- `QA_Report.md` – The full quality‑assurance report in Markdown format. It documents the testing methodology, which user flows could be accessed, which could not, any issues found, and actionable recommendations.
- `README.md` – This file, providing an overview of the deliverable.

## How to Use

Open `QA_Report.md` with any Markdown viewer (e.g., VS Code, GitHub, or a Markdown preview tool) to read the review findings.

If you need the report in PDF form, you can easily export the Markdown file using tools like `pandoc`:

```bash
pandoc QA_Report.md -o QA_Report.pdf
```
