# BOT Chain Onboarding Message

This repository contains a concise onboarding message (under 600 characters) that guides users through:

1. Connecting a BOT Chain wallet.
2. Signing a sponsored action.
3. Paying zero gas.

The message is stored in `onboarding_message.txt` and can be used directly in UI tooltips, help sections, or onboarding flows.

## Usage

Simply copy the content of `onboarding_message.txt` into the appropriate place in your application’s UI.
